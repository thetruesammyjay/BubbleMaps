# Bubblemaps Telegram Bot

A Telegram bot that analyzes token distribution using Bubblemaps API.

## Features
- Generate bubble map visualizations
- Show decentralization scores
- Display top holders and whale addresses
- Provide market data (price, volume, market cap)

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set up environment variables in `.env`
4. Run the bot: `python src/main.py`
